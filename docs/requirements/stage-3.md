## ③ 本阶段需求：批量记课 / 小班结算

小班课下，教练常常需要**一次给多位学员记课**：

1. 教练可以一次提交一批记课记录：同一 `kind`、同一上课日期、多位学员。
2. **全有或全无**：只要有一位学员记课失败（课时不足、过期、数据非法），**整批拒绝**，不得产生任何一条直接记课记录或扣课流水。
3. **逐项幂等**：每位学员一条 `operation_key`，重复提交同一批不得重复扣课；已成功处理过的项返回原记录。
4. 每位学员对对应课包必须有**可用的有效课时**（**遵守阶段 1 的有效期规则**）。
5. 上课日期不得晚于今天。
6. 完成后返回各条记课数据，并可看到相关学员的课时余额变化。

## ④ 不可违背的契约

遵守随附的《契约附件》。

**本阶段附加 API 契约（必须严格实现，供验收）：**

- 新增 `POST /api/v1/coach/lessons/batch/`，请求体：
  ```json
  {
    "kind": "private|group",
    "occurred_on": "YYYY-MM-DD",
    "operation_key": "<uuid>",
    "items": [
      {"student_id": 1, "operation_key": "<uuid>", "note": "", "exercises": []}
    ]
  }
  ```
- 语义：全有或全无；`items[].operation_key` 逐项幂等。
- 响应：`{"data": {"items": [ <lesson_data>, ... ]}}`。
